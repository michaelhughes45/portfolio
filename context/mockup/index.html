Process

How I build

Every feature follows the same loop, whether it's a login page or a battle engine.

01

Spec it

Write a short feature spec with goals and edge cases before writing any code.

02

Branch it

One branch per feature, with focused, conventional commits.

03

Test it

Unit tests for logic, then a check in the browser at desktop and phone sizes.

04

Ship it

Merge once the build and tests pass, then deploy to Vercel.
