problem: Calendars handle appointments and to-do apps handle tasks, but neither gives one morning view of the day, and neither shows how the week actually went.
solution: Task Master puts timed events and daily and weekly to-dos in one place, records what got done (and what was missed or done late), and turns it into a weekly review.

challenges:
  - title: Getting “today” right everywhere
    text: Every date is worked out in the user's own timezone. Daylight-saving gaps and repeated hours broke the obvious library approach, so time conversion is built on UTC offsets and tested against New York, Auckland, Havana and São Paulo edge cases.
  - title: Repeating items without storing every copy
    text: Rules are saved as RRULE strings and only expanded for the days on screen. Only completions and exceptions become rows, which is what makes “edit this one / this and following / all” possible.
  - title: A review that stays honest
    text: The weekly review is calculated from live data each time it loads, so ticking off a task late updates that week's numbers instead of freezing a snapshot.
