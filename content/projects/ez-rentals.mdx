challenges:
  - title: Deploying across two hosts
    text: With the frontend on Vercel and the API on Render, the port, allowed CORS origins and API URL all moved into environment variables, so the same code runs locally and in production.
  - title: A public demo visitors can't break
    text: Seeded demo listings and bookings are flagged, and the delete routes refuse to remove them. A scheduled GitHub Actions job also wakes the API every night and reseeds the database, so the demo starts fresh each day.
  - title: First steps in API security
    text: The API sanitizes MongoDB queries, rate-limits requests and only accepts calls from the allowed frontend, and Jest tests cover both the normal and the failure paths of the main routes. Login returns a token, but route-level token checks weren't added before the deadline. That's the first thing I'd fix.
